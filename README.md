
# Cayman Archer -- My Dashboard

A dashboard site built from scratch in HTML, JS, and CSS for WRIT 40363. It includes sample weather for Fort Worth and quotes relating to weather. 


**Live site:** https://caymanarcher.github.io/dashboard/ 

## Built with

- Semantic HTML5
- CSS 
- JavaScript
- Git and GitHub Pages
- Claude for finding quotes

## Notes

I created a dashboard for Fort Worth, Texas, with sample weather data and quotes related to weather. Enjoy a random quote or pretend it is always sunny and 70s on this website. A user can toggle from light or dark mode depending on personal preference, as well as shuffle through a varitey of quotes.
